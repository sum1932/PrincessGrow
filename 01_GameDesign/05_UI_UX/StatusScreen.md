# Status Screen

## 상태 화면 개요

캐릭터의 상세 정보를 확인하는 화면. 메인 화면에서 더 깊은 정보 제공.

---

## 화면 구성

### 전체 레이아웃

```
┌─────────────────────────────────────────────────────────────┐
│  [← 로가기]              [상태 확인]              [X]   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              [탭 메뉴]                            │    │
│  │  [캐릭터] [스탯] [NPC] [아이템] [도감]      │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  [탭별 내용 영역]                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 탭 1: 캐릭터 정보

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│              [캐릭터 일러스트]                            │
│                                                             │
│  이름: 루아 (레몬 스콘)                                   │
│  나이: 8세                                                │
│  성격: 활발한                                              │
│  성향: 사교적                                              │
│                                                             │
│  한마디: "오늘도 신나는 하루가 될 거예요!"                 │
│                                                             │
│  [의상 변경] [프로필 설정]                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

| 항목 | 내용 |
|------|------|
| **일러스트** | 현재 착용 의상의 캐릭터 CG |
| **이름** | 루아 + 본체 (레몬 스콘) |
| **나이** | 현재 연령 |
| **성격** | 스탯 비율에 따른 성향 |
| **성향** | 세부 성격 특성 |
| **한마디** | 성격에 따른 랜덤 대사 |

## 시각적 디자인

### 탭 메뉴 스타일

```
[캐릭터] [스탯] [NPC] [아이템] [도감]
  ↑
선택된 탭: 배경색 강조 + 아이콘
비선택 탭: 흐릿하게
```

### 색상 적용

| 탭 | 대표 색상 |
|-----|-----------|
| **캐릭터** | 코랄 핑크 |
| **스탯** | 스카이 블루 |
| **NPC** | 라벤더 |
| **아이템** | 민트 |
| **도감** | 골드 |

## 상호작용

### 네비게이션

| 동작 | 결과 |
|------|------|
| **탭 클릭** | 해당 탭 내용 표시 |
| **뒤로가기** | 메인 화면으로 |
| **X 버튼** | 메인 화면으로 |
| **스와이프** | 탭 간 이동 (모바일) |

### 특수 기능

| 기능 | 설명 |
|------|------|
| **스탯 터치** | 상세 설명 팝업 |
| **NPC 터치** | NPC 프로필 상세 |
| **아이템 터치** | 아이템 정보/사용 |
| **길게 누르기** | 상세 메뉴 |
