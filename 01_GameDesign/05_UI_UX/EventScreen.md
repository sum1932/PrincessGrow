# Event Screen

## 이벤트 화면 개요

스토리 진행과 캐릭터 간의 감정 교류를 담당하는 핵심 화면.

---

## 화면 구성

### 전체 레이아웃

```
┌─────────────────────────────────────────────────────────────┐
│  [← 건너뛰기]        [이벤트 제목]          [자동 ▶]    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│              [배경 이미지/톤]                            │
│                                                             │
│                    ┌─────────────┐                         │
│                    │             │                         │
│                    │  캐릭터    │                         │
│                    │    CG      │                         │
│                    │  (표정    │                         │
│                    │   변화)   │                         │
│                    │             │                         │
│                    └─────────────┘                         │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  [캐릭터명]                                               │
│                                                             │
│  "대화 내용이 여기에 표시됩니다.                          │
│   선택지가 있으면 아래에 선택 버튼이                      │
│   나타납니다."                                            │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  [선택지 1]                                               │
│  [선택지 2]                                               │
│  [선택지 3]                                               │
└─────────────────────────────────────────────────────────────┘
```

## 상세 구성

### 1. 상단바

```
┌─────────────────────────────────────────────────────────────┐
│  [← 건너뛰기]   생일 파티    [자동 ▶] [로그 📋]        │
└─────────────────────────────────────────────────────────────┘
```

| 요소 | 기능 | 설명 |
|------|------|------|
| **건너뛰기** | 이벤트 스킵 | 이미 본 이벤트만 가능 |
| **이벤트 제목** | 현재 이벤트명 | 고정 이벤트명 표시 |
| **자동** | 자동 진행 | 3초 간격으로 자동 대화 |
| **로그** | 대화 기록 | 이전 대사 확인 |

### 2. 비주얼 영역

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  [배경: 생일 파티 풍경]                                    │
│                                                             │
│         ┌─────────────────┐                                │
│         │                 │                                │
│         │   [루아       │                                │
│         │     표정:     │                                │
│         │     기쁨]     │                                │
│         │                 │                                │
│         └─────────────────┘                                │
│                                                             │
│         [이펙트: 반짝이는 효과]                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**구성 요소:**
- **배경**: 이벤트 상황에 맞는 일러스트 또는 색상 톤
- **캐릭터 CG**: 현재 대화 중인 캐릭터 (표정 변화)
- **이펙트**: 분위기 강조 효과 (파티클, 반짝임 등)

### 3. 대화 영역

```
┌─────────────────────────────────────────────────────────────┐
│  루아 (8세)                                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  "오늘은 내 생일이에요!                                    │
│   이노가 케이크를 준비했대요!                              │
│   너무 기대돼요~"                                          │
│                                                             │
│                                                    [다음 ▶]│
└─────────────────────────────────────────────────────────────┘
```

| 요소 | 설명 |
|------|------|
| **캐릭터명** | 말하는 캐릭터 이름 + 나이 |
| **대화 텍스트** | 현재 대사 (타이핑 효과) |
| **다음 버튼** | 다음 대사로 진행 |

### 4. 선택지 영역

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  🎂 케이크를 함께 자르자고 한다                     │   │
│  │     (도덕성 +5, 이노 호감도 +10)                    │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  🎁 선물을 먼저 열어보자고 한다                     │   │
│  │     (매력 +3, 스트레스 -5)                          │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  ❤️ 이노에게 고맙다고 말한다                        │   │
│  │     (이노 호감도 +15)                               │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

| 선택지 | 특징 |
|--------|------|
| **아이콘** | 선택지의 성격 표시 |
| **텍스트** | 선택 내용 |
| **효과 힌트** | 선택 시 예상 결과 (옵션) |

## 이벤트 타입별 화면

### 1. 고정 이벤트

**생일 이벤트 예시:**
```
[배경: 장식된 방]
[캐릭터: 루아 (파티복 착용)]
[효과: 색종이, 풍선]

루아: "와아! 생일 축하해주셔서 감사해요!"
```

**특징:**
- 고유한 배경과 CG
- 특별한 연출 효과
- 필수 진행 이벤트

### 2. 랜덤 이벤트

**길에서 동전 발견 예시:**
```
[배경: 거리]
[캐릭터: 루아 (평상복)]
[효과: 반짝이는 동전]

루아: "어라? 동전이 떨어져 있어요!"
```

**특징:**
- 일반적인 배경
- 간단한 CG
- 선택지 없거나 간단함

### 3. NPC 이벤트

**이노와의 대화 예시:**
```
[배경: 집 거실]
[캐릭터: 이노 (걱정 표정)]

이노: "루아, 요즘 많이 힘들지?"
```

**특징:**
- 1:1 대화 중심
- 호감도 변화
- 캐릭터별 고유 CG

### 4. 특별/히든 이벤트

**히든 이벤트 예시:**
```
[배경: 차원의 문]
[캐릭터: 루아 (신성한 분위기)]
[효과: 빛의 파장, 특수 이펙트]

루아: "이게... 제 진짜 힘인가요?"
```

**특징:**
- 특별한 배경/연출
- 중요한 스토리 진행
- 히든 엔딩 관련

## 시각적 디자인

### 배경 스타일

| 이벤트 타입 | 배경 스타일 | 색상 톤 |
|------------|------------|---------|
| **일상** | 평화로운 실내/외 | 밝은 톤 |
| **감동** | 따뜻한 분위기 | 따뜻한 색상 |
| **긴장** | 어두운 분위기 | 차가운 색상 |
| **히든** | 신비로운 분위기 | 형광색 계열 |

### 캐릭터 CG 표정

| 표정 | 상황 | 설명 |
|------|------|------|
| **기쁨** | 좋은 일 | 눈웃음, 환한 미소 |
| **슬픔** | 안 좋은 일 | 눈물, 내려간 입꼬리 |
| **놀람** | 갑작스러운 일 | 눈 크게, 입 벌림 |
| **분노** | 화난 상황 | 찡그린 눈, 굳은 표정 |
| **수줍음** | 민망한 상황 | 붉어진 볼, 고개 숙임 |

### 폰트 스타일

| 용도 | 폰트 | 효과 |
|------|------|------|
| **캐릭터명** | 둥근모꼴 (볼드) | 그림자 효과 |
| **대사** | 나눔고딕 | 타이핑 효과 |
| **선택지** | 나눔고딕 | 호버 시 강조 |
| **효과** | 나눔고딕 (볼드) | 색상 강조 |

## 상호작용

### 기본 조작

| 입력 | 동작 |
|------|------|
| **화면 터치** | 다음 대사로 |
| **스페이스바** | 다음 대사로 (PC) |
| **엔터** | 다음 대사로 (PC) |
| **ESC** | 메뉴/스킵 |

### 고급 기능

| 기능 | 설명 |
|------|------|
| **자동 진행** | 설정한 속도로 자동 대화 |
| **대사 스킵** | 현재 대사 즉시 완료 |
| **이벤트 스킵** | 이미 본 이벤트 생략 |
| **대사 로그** | 이전 대사 확인 |
| **되감기** | 1턴 전 대사로 (제한적) |

### 선택지 상호작용

| 동작 | 결과 |
|------|------|
| **선택지 터치** | 해당 선택지 선택 |
| **길게 누르기** | 선택지 효과 상세 확인 |
| **밖 터치** | 선택 취소 (가능한 경우) |

## 애니메이션

### 대사 진행

| 효과 | 설명 | 시간 |
|------|------|------|
| **타이핑** | 한 글자씩 나타남 | 0.03초/글자 |
| **페이드 인** | 전체 대사 페이드 | 0.2초 |
| **스킵** | 즉시 전체 표시 | 0초 |

### 화면 전환

| 상황 | 효과 | 시간 |
|------|------|------|
| **이벤트 진입** | 페이드 인 + 줌 인 | 0.5초 |
| **캐릭터 전환** | 슬라이드 | 0.3초 |
| **배경 전환** | 크로스 페이드 | 0.5초 |
| **이벤트 종료** | 페이드 아웃 | 0.3초 |

### 특수 효과

| 효과 | 상황 | 설명 |
|------|------|------|
| **반짝임** | 행복한 순간 | 황금색 파티클 |
| **그림자** | 긴장감 | 어두운 톤 |
| **흔들림** | 충격 | 화면 흔들림 |
| **빛** | 히든/신성 | 빛 기둥 |
