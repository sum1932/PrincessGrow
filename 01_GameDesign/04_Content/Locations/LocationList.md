# Locations

## 방문 가능한 장소

---

## 일반 장소

### 1. 집 (Home)

| 항목 | 내용 |
|------|------|
| **위치** | 인간 세계 주거지 |
| **설명** | 이노와 루아가 함께 사는 곳. 1인용 아파트였으나 루아가 오게 되어 2인용으로 변경. |
| **특징** | 안전하고 편안한 공간 |
| **이벤트** | 일상 이벤트, 휴식 이벤트 |
| **NPC** | 이노 |

#### 상세 설명
- **거실**: TV, 소파, 식탁
- **주방**: 이노가 요리하는 공간
- **루아의 방**: 침대, 책상, 옷장
- **이노의 방**: 간소한 생활 공간
- **베란다**: 작은 텃밭

#### 특별한 점
- 차원의 문이 열린 곳
- 루아의 첫 발걸음

---

### 2. 학교 (School)

| 항목 | 내용 |
|------|------|
| **위치** | 인간 세계 교육 기관 |
| **설명** | 루아가 인간 아이들과 함께 교육받는 곳 |
| **개방 시기** | 6세부터 |
| **이벤트** | 입학식, 졸업식, 교우 이벤트 |
| **NPC** | 리안, 교사, 학생들 |

#### 상세 설명
- **초등학교**: 6~12세
- **중학교**: 12~15세
- **고등학교**: 15~18세 (선택)

#### 특별한 점
- 루아가 처음으로 인간 아이들과 어울리는 곳
- 리안과 만나는 곳

---

### 3. 공원 (Park)

| 항목 | 내용 |
|------|------|
| **위치** | 근처 공원 |
| **설명** | 산책과 휴식을 위한 공간 |
| **이벤트** | 산책 이벤트, 계절 이벤트 |
| **NPC** | 카일 (드물게) |

#### 상세 설명
- **벤치**: 쉬는 곳
- **운동 기구**: 체력 단련
- **연못**: 고요한 풍경
- **꽃밭**: 봄/여름 꽃

#### 계절별 변화
- **봄**: 벚꽃
- **여름**: 푸른 나무
- **가을**: 단풍
- **겨울**: 눈 덮인 풍경

## 특별 장소

### 6. 디저트 왕국 (Dessert Kingdom)

| 항목 | 내용 |
|------|------|
| **위치** | 차원 너머 |
| **설명** | 디저트들이 사는 왕국 |
| **개방 시기** | 특별 이벤트 시 |
| **이벤트** | 귀환 이벤트, 여왕 이벤트 |
| **NPC** | 왕국 주민, 여왕 |

#### 주요 지역
- **왕궁**: 여왕과 귀족의 거주지
- **번화가**: 상점, 카페
- **교육 구역**: 학교, 도서관
- **자연 구역**: 공원, 숲

#### 특별한 점
- 인간에게는 보이지 않음
- 루아의 본래 고향

| **이벤트** | 프로로그, 특별 이벤트 |

- 히든 엔딩과 관련

## 장소 연계 이벤트

### 히든 장소

#### 비밀의 정원
- **조건**: 모든 NPC 호감도 80+
- **장소**: 공원 깊숙이
- **이벤트**: 히든 이벤트 1

#### 차원의 정거장
- **조건**: 히든 엔딩 2 조건 충족
- **장소**: 차원의 문 근처
- **이벤트**: 히든 엔딩 2
