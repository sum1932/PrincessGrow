# Art Style Guide

## 아트 스타일 개요

디저트 판타지 세계관을 표현하는 Cute/Soft 스타일

---

## 전체 방향성

### 핵심 키워드
- **Cute (귀여움)**: 둥근 형태, 부드러운 색상
- **Soft (부드러움)**: 따뜻한 톤, 편안한 분위기
- **Sweet (달콤함)**: 디저트 컨셉, 파스텔 색상
- **Fantasy (판타지)**: 신비로운 세계관, 독창적 디자인

### 레퍼런스
- **일러스트 스타일**: "Princess Maker" 시리즈, "Volcano Princess"
- **캐릭터 디자인**: SD 캐릭터 + 정면 일러스트
- **배경**: 수채화 느낌, 따뜻한 색조
- **UI**: "Animal Crossing", "Stardew Valley"의 편안한 느낌

## 캐릭터 아트

### 캐릭터 스타일

#### 루아 (육성 대상)
| 항목 | 스펙 |
|------|------|
| **스타일** | 2.5~3 헤드 비율의 SD 캐릭터 |
| **비율** | 머리가 큰 Cute SD |
| **눈** | 큰 눈, 반짝이는 느낌 |
| **표정** | 풍부한 감정 표현 (8종 이상) |
| **의상** | 15~20종의 의상 변화 |
| **포즈** | 스탠딩 CG, 정면/45도 |

#### 이노 & NPC
| 항목 | 스펙 |
|------|------|
| **스타일** | 4~5 헤드 비율 |
| **비율** | 현실적이지만 귀여운 비율 |
| **포즈** | 스탠딩 CG, 다양한 각도 |
| **표정** | 상황별 표정 변화 |

### 일러스트 종류

| 타입 | 해상도 | 용도 |

## UI 그래픽

### UI 요소 스타일

#### 버튼
```
┌──────────────────┐
│                  │
│   둥근 모서리    │  ← border-radius: 15px
│   그라데이션     │  ← 상단 밝게 → 하단 어둡게
│   부드러운 그림자│  ← 0 4px 8px rgba(0,0,0,0.1)
│                  │
└──────────────────┘
```

#### 패널/창
```
┌──────────────────┐
│   제목 영역      │  ← 상단 둥근 모서리
├──────────────────┤
│                  │
│   내용 영역      │  ← 패딩: 20px
│                  │
└──────────────────┘
     ← 하단 둥근 모서리
```

#### 게이지/바
```
[배경: 연한 회색 #F0F0F0]
[채움: 그라데이션]    ← border-radius: 15px
[테두리: 둥근 사각형]
```

## 파일 네이밍 규칙

### 캐릭터
```
[캐릭터명]_[타입]_[번호]

예시:
- Lua_standing_001.png
- Lua_expression_happy.png
- Ino_standing_001.png
```

### 배경
```
[BG]_[장소]_[시간]

예시:
- BG_home_day.png
- BG_park_night.png
- BG_school_classroom.png
```

### UI
```
[UI]_[요소]_[상태]

예시:
- UI_button_default.png
- UI_button_hover.png
- UI_panel_window.png
```

### 아이콘
```
[ICON]_[이름]

예시:
- ICON_heart.png
- ICON_money.png
- ICON_calendar.png
```
