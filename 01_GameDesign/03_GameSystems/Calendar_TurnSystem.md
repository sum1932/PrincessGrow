## 챕터 구분

### 챕터 1: 어린 시절
- **기간**: 6세 ~ 10세
- **턴**: 0 ~ 48턴 (48턴)
- **테마**: 적응과 성장
- **특징**:
  - 기본 시스템 학습
  - 초등학교 입학 이벤트
  - 단순한 활동 선택
  - 밝고 순수한 분위기

### 챕터 2: 성장기
- **기간**: 10세 ~ 15세
- **턴**: 48 ~ 108턴 (60턴)
- **테마**: 자아 형성
- **특징**:
  - 다양한 활동 개방
  - NPC 관계 심화
  - 중학교 진학
  - 성격 성향 확정
  - 미래에 대한 고민 시작

### 챕터 3: 청소년기
- **기간**: 15세 ~ 18세
- **턴**: 108 ~ 144턴 (36턴)
- **테마**: 결단과 결말
- **특징**:
  - 고등학교 진학 (선택)
  - 엔딩 준비
  - 주요 NPC 이벤트 집중
  - 최종 선택의 순간

## 월/계절 시스템

### 월별 구분
게임 내 12개월은 실제와 동일한 계절을 따름

| 월 | 계절 | 주요 이벤트 |
|----|------|------------|
| 1월 | 겨울 | 신년 이벤트 |
| 2월 | 겨울 | 발렌타인 이벤트 |
| 3월 | 봄 | 봄 방학, 입학식 |
| 4월 | 봄 | 벚꽃 이벤트 |
| 5월 | 봄 | 어린이날, 부모님 이벤트 |
| 6월 | 여름 | 여름 방학 시작 |
| 7월 | 여름 | 해변 이벤트 |
| 8월 | 여름 | 여름 방학 |
| 9월 | 가을 | 2학기 시작 |
| 10월 | 가을 | 운동회, 단풍 |
| 11월 | 가을 | 추수감사절 |
| 12월 | 겨울 | 크리스마스, 연말, 루아 생일(24일) |

### 계절별 특징

#### 봄 (3~5월)
- **분위기**: 새로움, 시작
- **특별 활동**: 등산, 꽃구경, 피크닉
- **이벤트**: 입학식, 벚꽃축제

#### 여름 (6~8월)
- **분위기**: 활기, 방학
- **특별 활동**: 해변, 수영, 여행
- **이벤트**: 여름방학, 불꽃놀이

#### 가을 (9~11월)
- **분위기**: 성숙, 수확
- **특별 활동**: 단풍구경, 운동회
- **이벤트**: 운동회, 단풍놀이

#### 겨울 (12~2월)
- **분위기**: 따뜻함, 연말
- **특별 활동**: 눈놀이, 크리스마스
- **이벤트**: 크리스마스, 연말파티, 생일

## 턴 진행 시스템

### 턴 진행 순서

```
[턴 시작]
    ↓
[UI 업데이트]
  - 현재 날짜/연령 표시
  - 스탯 현황 표시
  - 이벤트 알림 (있을 경우)
    ↓
[일정 선택 단계]
  ┌─────────────────────────────┐
  │  1. 첫 번째 활동 선택        │
  │  2. 두 번째 활동 선택        │
  │  3. 선택 완료 확인           │
  └─────────────────────────────┘
    ↓
[활동 진행]
  ┌─────────────────────────────┐
  │  활동 1 결과 적용           │
  │    - 스탯 변화              │
  │    - 스트레스 변화          │
  │    - 비용 처리              │
  │                             │
  │  활동 2 결과 적용           │
  │    - 스탯 변화              │
  │    - 스트레스 변화          │
  │    - 비용 처리              │
  └─────────────────────────────┘
    ↓
[월간 정산]
  - 생활비 지출
  - 기본 스트레스 변화
  - 특별 조건 체크
    ↓
[이벤트 체크]
  ┌─────────────────────────────┐
  │  1. 고정 이벤트 체크         │
  │     (연령/날짜 기반)         │
  │  2. 랜덤 이벤트 체크         │
  │     (확률/스탯 기반)         │
  │  3. NPC 이벤트 체크          │
  │     (호감도/조건 기반)       │
  │  4. 생일/기념일 체크         │
  └─────────────────────────────┘
    ↓
[이벤트 발생 시]
  ┌─────────────────────────────┐
  │  - 이벤트 씬 재생           │
  │  - 선택지 진행 (있을 경우)   │
  │  - 결과 적용                │
  └─────────────────────────────┘
    ↓
[턴 종료 처리]
  ┌─────────────────────────────┐
  │  - 데이터 저장              │
  │  - 스트레스 한도 체크       │
  │  - 특별 상태 체크           │
  │  - 연령 업데이트            │
  └─────────────────────────────┘
    ↓
[다음 턴] 또는 [엔딩]
```

### 턴당 소요 시간
- **일정 선택**: 자유 (시간제한 없음)
- **활동 진행**: 약 5초 (애니메이션)
- **이벤트**: 약 30초 ~ 2분 (이벤트 길이에 따라)
- **평균 턴당 플레이 시간**: 약 1~2분
