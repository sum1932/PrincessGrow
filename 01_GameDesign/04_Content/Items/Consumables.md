# 소비 아이템 (Consumables)

> **참고**: 이 문서는 DataSchema.md의 `Items_Master` 테이블 구조를 따릅니다.
> 
> - `Type`: Consumable
> - 사용 시 소모되며, 스탯이나 상태를 즉시 변화시킵니다.

---

## 스키마 구조

| 컬럼 | 설명 | 예시 |
|------|------|------|
| **Item_ID** | 아이템 고유 ID | ITEM_001 |
| **Name_KO** | 한글 이름 | 영양제 |
| **Type** | 아이템 타입 | Consumable |
| **Category** | 세부 카테고리 | Recovery / StatBoost / Special |
| **Rarity** | 희귀도 (1-5) | 1=★☆☆☆☆ |
| **Price** | 가격 | 100 |
| **Description** | 설명 | 건강을 챙기는 기본 영양제 |
| **Effect_HP** | 체력 변화 | +10 |
| **Effect_Charm** | 매력 변화 | 0 |
| **Effect_Int** | 지능 변화 | 0 |
| **Effect_Art** | 예술 변화 | 0 |
| **Effect_Morality** | 도덕성 변화 | 0 |
| **Effect_Stress** | 스트레스 변화 | -5 |
| **Max_Stack** | 최대 중첩 수량 | 99 |

## 게임 밸런싱 참고

### 초반 전략 (6~10세)
- **추천**: 저렴한 회복 아이템 (영양제, 진정 티백)
- **목적**: 스트레스 관리 및 기본 체력 유지
- **예산**: 50-100G

### 중반 전략 (11~15세)
- **추천**: 스탯 강화 아이템 집중
- **목적**: 목표 엔딩에 맞는 스탯 성장
- **예산**: 100-200G

### 후반 전략 (16~18세)
- **추천**: 고급 스탯 강화 아이템
- **목적**: 엔딩 조건 충족을 위한 마무리
- **예산**: 200G+

## DataSchema 연동 정보

### 테이블: Items_Master
- **Type**: Consumable
- **Category**: Recovery / StatBoost / Special
- **Is_Consumable**: TRUE (사용 시 소모)
- **Is_Sellable**: TRUE (판매 가능)
- **Target_NPC**: All (모든 NPC 사용 가능)

### CSV 파일 참조
통합된 Items_Master.csv에서 다음 Type을 필터링:
```sql
SELECT * FROM Items_Master 
WHERE Type = 'Consumable' 
ORDER BY Category, Item_ID;
```
