## 주인공

### 이노 (Ino)

| 항목 | 내용 |
|------|------|
| **본체** | 토피넛 라떼 (Toffee Nut Latte) |
| **나이** | 21세 |
| **성별** | 남성 |
| **직업** | 인간 세계 조사 담당원 |

### 외형
- 따뜻한 베이지 톤의 머리카락
- 밝은 녹색 눈동자
- 편안하고 친근한 인상
- 주로 캐주얼한 옷차림

### 성격
- **상냥함**: 누구에게나 친절하게 대함
- **활발함**: 밝고 긍정적인 에너지
- **서투름**: 주위를 살피는 능력이 부족
  - 물건을 자주 부숨
  - 일 처리가 미숙
  - 하지만 성격이 좋아 주변에서 넘어감
- **열정적**: 맡은 일에 최선을 다함

### 배경
- 왕국에서 평범하게 자란 디저트
- 인간 세계 조사 업무에 관심을 가지고 지원
- 현재 인간 세계에서 2년째 조사 임무 중
- 혼자서 지내다가 갑작스럽게 딸(루아)을 맡게 됨

### 특징
- 토피넛 라떼 특유의 달콤하고 고소한 분위기
- 커피 향이 은은하게 풍김
- 따뜻한 온기를 가진 존재
- 루아에게 존댓말을 사용함

## 육성 대상

### 루아 (Lua)

| 항목 | 내용 |
|------|------|
| **본체** | 레몬 스콘 (Lemon Scone) |
| **나이** | 6세 (게임 시작 시) → 18세 (게임 종료) |
| **성별** | 여성 |
| **신분** | 차기 여왕 후보 |

### 외형
- 밝은 금발 (레몬색)
- 맑은 노란색 눈동자, 동공은 흰색
- 어딘가 맹한 인상
- 전반적으로 얌전하고 행동 반경이 적음

### 성격 (성장하면서 변화)
- **6~10세**: 순수하고 호기심 많음
- **10~15세**: 자신감 생김, 리더십 발현
- **15~18세**: 성숙해지면서 여왕의 자질 갖춤

### 배경
- 왕궁에서 특별하게 자란 디저트
- 어릴 때부터 여왕의 자질을 인정받음
- 인간 세계 경험의 필요성으로 이노에게 맡겨짐
- **참고**: 여왕이 되고 싶지 않으면 그만둘 수 있음 (자율 선택)

### 특징
- 레몬 스콘 특유의 상큼하고 깔끔한 분위기
- 단맛과 신맛의 조화
- 처음에는 차갑게 느껴질 수 있지만 알고 보면 따뜻함
- 특별한 잠재력을 가짐

### 성장 목표
- 인간 세계에 대한 이해
- 다양한 경험을 통한 성장
- 스스로 선택하는 미래 (여왕 or 다른 길)

## 주요 NPC

### 1. 아이린 (Aileen) - 소꿉친구

| 항목 | 내용 |
|------|------|
| **본체** | 마카롱 (Macaron) |
| **나이** | 21세 (이노와 동갑) |
| **성별** | 여성 |
| **관계** | 이노의 소꿉친구 |

#### 외형
- 파스텔 톤의 다채로운 머리카락
- 큰 눈동자와 귀여운 인상
- 화려하고 패셔너블한 옷차림

#### 성격
- **밝고 사교적**: 사람들과 어울리기를 좋아함
- **세심함**: 이노의 서투른 점을 잘 챙김
- **적극적**: 원하는 것을 솔직하게 표현

#### 배경
- 이노와 같은 동네에서 자라남
- 현재 왕국에서 패션 관련 일을 함
- 이노가 인간 세계로 가도 계속 연락하며 지냄
- 루아를 처음 보고 귀여워하며 자주 놀러 옴

#### 특징
- 마카롱 특유의 달콤하고 다채로운 매력
- 눈에 띄는 존재감
- 이노와는 썸? 같은 관계 (플레이어 선택에 따라 발전 가능)

### 2. 카일 (Kyle) - 호위/경호원

| 항목 | 내용 |
|------|------|
| **본체** | 블랙 티 (Black Tea) |
| **나이** | 25세 |
| **성별** | 남성 |
| **관계** | 루아의 호위 기사 |

#### 외형
- 짙은 갈색의 단정한 머리
- 날카로운 눈매
- 정제된 매너와 옷차림
- 항상 차분한 표정

#### 성격
- **신중함**: 행동에 항상 여유가 있음
- **충성심**: 루아를 진심으로 보호함
- **엄격함**: 원칙을 중시함
- **따뜻함**: 겉으로는 차갑지만 속으로는 걱정 많음

#### 배경
- 왕궁 경호대 출신
- 루아가 어렸을 때부터 담당
- 인간 세계에서는 멀리서 루아를 지켜봄
- 이노에게 직접 도움을 주지는 않으나 필요시 정보 제공

#### 특징
- 블랙 티 특유의 차분하고 깊은 분위기
- 깔끔하고 품위 있는 언행
- 루아의 안전을 최우선으로 생각

### 3. 리안 (Lian) - 인간

| 항목 | 내용 |
|------|------|
| **본체** | 인간 (특별한 능력 보유) |
| **나이** | 19세 |
| **성별** | 남성 |
| **관계** | 루아의 첫 인간 친구 |

#### 외형
- 평범하지만 친근한 인상
- 학생 같은 옷차림
- 밝은 미소

#### 성격
- **호기심 많음**: 특별한 존재(디저트)를 볼 수 있는 능력에 대한 의문
- **친절함**: 루아에게 거리낌 없이 다가감
- **순수함**: 세상에 대한 편견이 없음

#### 배경
- 평범한 인간 가정에서 자람
- 어릴 때부터 특별한 존재(디저트)들을 볼 수 있음
- 주변에 이 사실을 알리지 않고 지냄
- 우연히 루아를 만나 친구가 됨

#### 특징
- 디저트 왕국의 존재를 알고 있음
- 루아에게 인간 세계의 정보나 도움을 줌
- **히든 요소**: 리안의 능력의 비밀 (히든 엔딩 관련)
