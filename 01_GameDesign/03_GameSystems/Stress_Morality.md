# Stress & Morality System

## 스트레스 시스템

### 개요
스트레스는 육성 활동의 부산물. 적절한 관리가 필요한 시스템.

### 스트레스 특성
| 항목 | 내용 |
|------|------|
| **초기값** | 0 |
| **최대값** | 100 |
| **경고선** | 70 |
| **한계선** | 100 |

### 스트레스 증가 요인

| 활동/상황 | 증가량 | 비고 |
|-----------|--------|------|
| **수업** | +8~15 | 수업 종류에 따라 다름 |
| **아르바이트** | +5~12 | 아르바이트 종류에 따라 다름 |
| **고수익 활동** | +15~20 | 높은 수익 = 높은 스트레스 |
| **이벤트 실패** | +10~20 | 선택지 결과 |
| **경제적 어려움** | +5~10 | 잔고 부족 시 |
| **NPC 갈등** | +10~15 | 관계 악화 |
| **계절 변화** | +3~5 | 특정 계절 |

### 스트레스 감소 요인

| 활동/상황 | 감소량 | 비고 |
|-----------|--------|------|
| **휴식** | -20~-50 | 휴식 종류에 따라 다름 |
| **성공 이벤트** | -10~-20 | 좋은 선택지 결과 |
| **NPC 긍정 이벤트** | -10~-15 | 호감도 상승 |
| **특별 활동** | -15~-30 | 여행, 축제 등 |
| **생일/기념일** | -30~-50 | 특별한 날 |
| **선물 받음** | -5~-10 | 아이템 효과 |

### 스트레스 단계별 효과

#### 정상 (0~30)
| 항목 | 효과 |
|------|------|
| **상태** | 최상의 컨디션 |
| **스탯 효율** | 100% |
| **이벤트** | 긍정 이벤트 확률 +10% |
| **특징** | 모든 활동 최적 효과 |

#### 양호 (31~50)
| 항목 | 효과 |
|------|------|
| **상태** | 약간 피곤 |
| **스탯 효율** | 100% |
| **이벤트** | 일반적 |
| **특징** | 특별한 변화 없음 |

#### 피로 (51~70)
| 항목 | 효과 |
|------|------|
| **상태** | 피로 누적 |
| **스탯 효율** | 90% |
| **이벤트** | 스트레스 관련 이벤트 발생 가능 |
| **특징** | 경고 신호 |

#### 과로 (71~90)
| 항목 | 효과 |
|------|------|
| **상태** | 심각한 피로 |
| **스탯 효율** | 75% |
| **이벤트** | 스트레스 이벤트 확률 +30% |
| **특징** | 강제 휴식 권장 |
| **건강** | 질병 발생 확률 +20% |

#### 한계 (91~100)
| 항목 | 효과 |
|------|------|
| **상태** | 한계 직전 |
| **스탯 효율** | 50% |
| **이벤트** | 강제 이벤트 발생 |
| **특징** | 반드시 휴식 필요 |
| **건강** | 질병 발생 확률 +50% |

#### 위험 (100+)
| 항목 | 효과 |
|------|------|
| **상태** | 붕괴 위험 |
| **스탯 효율** | 30% |
| **이벤트** | 강제 쉬게 됨 이벤트 |
| **특징** | 자동으로 휴식 턴 |
| **도덕성** | -10 감소 |

### 스트레스 관련 이벤트

| 이벤트명 | 발생 조건 | 내용 | 효과 |
|----------|-----------|------|------|
| **쉬어야 해요** | 70+ | 루아가 피로 호소 | 휴식 권장 |
| **감기 걸림** | 80+ | 면역력 저하 | 체력 -15, 강제 휴식 |
| **우연한 휴식** | 90+ | 강제로 쉬게 됨 | 스트레스 -40 |
| **번아웃** | 100+ | 극도의 피로 | 스트레스 -50, 모든 스탯 -10 |

## 도덕성 시스템

### 개요
도덕성은 루아의 양심과 행동의 올바름을 나타냄.

### 도덕성 특성
| 항목 | 내용 |
|------|------|
| **초기값** | 50 |
| **범위** | 0~999 |
| **등급** | 악함(0~199) / 보통(200~399) / 선함(400+) |

### 도덕성 상승 요인

| 활동/선택 | 상승량 | 비고 |
|-----------|--------|------|
| **도덕 수업** | +10 | 정기적 수업 |
| **봉사활동** | +15 | 공원 청소 등 |
| **선행 선택** | +5~+15 | 이벤트 선택지 |
| **도움 요청 승낙** | +5 | NPC 도움 |
| **정직한 행동** | +10 | 정직한 선택 |

### 도덕성 하락 요인

| 활동/선택 | 하락량 | 비고 |
|-----------|--------|------|
| **비도덕적 선택** | -10~-20 | 나쁜 선택지 |
| **거짓말** | -5~-15 | 이벤트 선택 |
| **편법 아르바이트** | -15 | 위험한 아르바이트 |
| **NPC 배신** | -20 | 관계 악화 |
| **과도한 스트레스** | -10 | 100+ 스트레스 |
| **사기** | -30 | 사기 이벤트 |

### 도덕성 단계별 특성

#### 악함 (0~199)
| 항목 | 효과 |
|------|------|
| **성격** | 이기적, 계산적 |
| **NPC 반응** | 거리낌, 불신 |
| **엔딩** | 어두운 엔딩 가능 |
| **이벤트** | 비도덕적 선택지 추가 |
| **제한** | 특정 이벤트 불가 |

#### 보통 (200~399)
| 항목 | 효과 |
|------|------|
| **성격** | 일반적인 |
| **NPC 반응** | 보통 |
| **엔딩** | 중립적 엔딩 |
| **이벤트** | 일반적 |
| **특징** | 대부분의 플레이어 위치 |

#### 선함 (400+)
| 항목 | 효과 |
|------|------|
| **성격** | 착함, 배려심 |
| **NPC 반응** | 신뢰, 호감 |
| **엔딩** | 선한 엔딩, 여왕 엔딩 가능 |
| **이벤트** | 선한 선택지 추가 |
| **특별** | 히든 엔딩 조건 충족 |

### 도덕성 관련 이벤트

| 이벤트명 | 발생 조건 | 내용 | 효과 |
|----------|-----------|------|------|
| **착한 아이** | 도덕성 400+ | 루아의 선행 | 호감도 상승 |
| **도덕적 갈등** | 선택지 | 양심의 갈등 | 도덕성 변화 |
| **타락** | 도덕성 100- | 마음의 변화 | 어두운 이벤트 |
| **구원** | 악함→선함 | 마음의 회심 | 도덕성 +50 |

## 스트레스와 도덕성의 관계

### 상호작용
| 상황 | 스트레스 | 도덕성 | 결과 |
|------|----------|--------|------|
| **과로** | 높음 | - | 도덕성 -10 |
| **번아웃** | 100+ | - | 도덕성 -20 |
| **휴식 충분** | 낮음 | - | 도덕성 +5 |
| **악함+스트레스** | 높음 | 낮음 | 최악의 상태 |
| **선함+스트레스** | 높음 | 높음 | 희생적 헌신 |

### 균형 관리
- **이상적**: 스트레스 낮음 + 도덕성 높음
- **위험적**: 스트레스 높음 + 도덕성 낮음
- **현실적**: 중간값 유지

## 전략 가이드

### 스트레스 관리
1. **정기적 휴식**: 턴 3~4회마다 휴식
2. **이벤트 활용**: 긍정 이벤트로 감소
3. **NPC 관리**: 좋은 관계 유지
4. **경제 여유**: 여유로운 자금 관리

### 도덕성 관리
1. **선택지 주의**: 도덕적 선택
2. **도덕 수업**: 정기적 수강
3. **봉사활동**: 아르바이트 대안
4. **NPC 관계**: 정직한 대화
