# Multi-Ending System

## 엔딩 시스템 개요

### 엔딩 종류
| 종류 | 수 | 특징 |
|------|-----|------|
| **기본 엔딩** | 13개 | 일반적인 조건으로 달성 |
| **히든 엔딩** | 2개 | 특수한 조건 필요 |
| **배드 엔딩** | 0개 | 없음 (모든 엔딩에 의미 부여) |
| **총계** | 15개 | - |

### 엔딩 판정 시점
- **18세 마지막 턴 종료 후**
- 최종 스탯 + NPC 호감도 + 선택지 기록 종합 판정

## 엔딩 판정 로직

### 판정 순서
```
1. [히든 엔딩 2 조건 체크]
   └─ 충족 → 히든 엔딩 2
   └─ 미충족 → 2단계

2. [히든 엔딩 1 조건 체크]
   └─ 충족 → 히든 엔딩 1
   └─ 미충족 → 3단계

3. [기본 엔딩 우선순위 체크]
   └─ 여왕의 길 → 지능 500+, 도덕성 500+
   └─ 현명한 학자 → 지능 600+
   └─ 반짝이는 아이돌 → 매력 600+
   └─ 예술가의 길 → 예술 600+
   └─ 강인한 운동선수 → 체력 600+
   └─ 성스러운 성녀 → 도덕성 600+
   └─ 인간 세계 탐구자 → 리안 호감도 + 조건
   └─ 따뜻한 교사 → 지능 + 도덕성
   └─ 요리 연구가 → 예술 + 특별 조건
   └─ 사교적 리더 → 매력 + NPC 호감도
   └─ 균형잡힌 인재 → 모든 스탯 균형
   └─ 평범한 행복 → 기본값
   └─ 자유로운 영혼 → 특별 선택지
```

### 우선순위 규칙
1. **히든 엔딩 우선**: 히든 조건 충족 시 무조건 히든 엔딩
2. **스탯 우선**: 높은 스탯 조건을 먼저 체크
3. **복합 조건**: 스탯 + 관계 조합
4. **특별 선택지**: 특정 선택지 필요한 엔딩
