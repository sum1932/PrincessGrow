## 시스템별 설명

### 1. Calendar System (달력/턴 시스템)
**핵심**: 시간의 흐름 관리
- **기간**: 6세 ~ 18세 (12년)
- **단위**: 1개월 = 1턴
- **총 턴**: 144턴
- **챕터**: 3개 챕터로 구분
  - 챕터 1: 6~10세 (48턴)
  - 챕터 2: 10~15세 (60턴)
  - 챕터 3: 15~18세 (36턴)

### 2. Schedule System (일정 시스템)
**핵심**: 플레이어의 선택
- **월간 선택**: 한 달에 2개 활동 선택
- **활동 종류**:
  - 수업 (스탯 상승, 비용 발생)
  - 아르바이트 (수입, 스탯 소폭 상승)
  - 휴식 (스트레스 감소)
  - 외출 (NPC 만남, 이벤트 발생)
  - 특별 활동 (계절/시즌 한정)

### 3. Character Growth System (캐릭터 성장)
**핵심**: 루아의 성장 관리
- **스탯**: 6개
  - 체력 (HP)
  - 매력 (Charm)
  - 지능 (Intelligence)
  - 예술 (Art)
  - 도덕성 (Morality)
  - 스트레스 (Stress)
- **성장**: 활동에 따른 스탯 변화
- **성격**: 스탯 비율에 따른 성향 변화

### 4. Event System (이벤트 시스템)
**핵심**: 스토리 진행과 변화
- **고정 이벤트**: 연령/날짜 기반
- **랜덤 이벤트**: 스탯/확률 기반
- **NPC 이벤트**: 호감도 기반
- **특별 이벤트**: 생일, 계절, 히든

### 5. Economy System (경제 시스템)
**핵심**: 자원 관리
- **수입**: 아르바이트, 기본 생활비
- **지출**: 수업비, 생활비, 아이템 구매
- **전략**: 수입과 지출의 균형
- **난이도**: 중간 (경제 압박 있음)

### 6. Ending System (엔딩 시스템)
**핵심**: 결과 결정
- **기본 엔딩**: 13개
- **히든 엔딩**: 2개
- **조건**: 복합 (스탯 + NPC 관계 + 선택지)

## 시스템 연관도

### 데이터 흐름
```
[플레이어 선택] 
    ↓
[일정 선택] → 스탯 변화 + 스트레스 변화 + 비용 발생
    ↓
[턴 종료] → 스탯 체크 → 이벤트 발생 여부 확인
    ↓
[이벤트 진행] → NPC 호감도 변화 + 추가 스탯 변화
    ↓
[다음 턴] 또는 [엔딩 판정]
```

### 주요 연관 관계
| 시스템 A | 시스템 B | 연관 내용 |
|---------|---------|----------|
| 일정 | 스탯 | 활동에 따른 스탯 상승/하락 |
| 일정 | 경제 | 수업비, 수입 관리 |
| 일정 | 스트레스 | 활동에 따른 스트레스 변화 |
| 스탯 | 이벤트 | 특정 스탯 조건에서 이벤트 발생 |
| 스트레스 | 이벤트 | 스트레스 수치에 따른 이벤트 |
| NPC | 이벤트 | 호감도에 따른 전용 이벤트 |
| 스탯 | 엔딩 | 스탯 조합으로 엔딩 결정 |
| NPC | 엔딩 | 특정 NPC와의 관계로 엔딩 변화 |

## 게임 진행 흐름

### 1턴의 진행 순서

```
1. [턴 시작]
   ↓
2. [일정 선택 화면]
   - 2개 활동 선택
   - 비용/효과 미리보기
   ↓
3. [활동 진행]
   - 활동 1 → 결과 반영
   - 활동 2 → 결과 반영
   ↓
4. [이벤트 체크]
   - 고정 이벤트 확인
   - 랜덤 이벤트 확률 체크
   - NPC 이벤트 체크
   ↓
5. [이벤트 발생 시]
   - 이벤트 진행
   - 선택지 (있을 경우)
   - 결과 반영
   ↓
6. [턴 종료]
   - 스탯 변화 적용
   - 스트레스 체크
   - 다음 턴 준비
   ↓
7. [특별 체크]
   - 생일?
   - 연령 변화?
   - 챕터 변화?
   ↓
8. [반복 또는 엔딩]
```

## 주요 인터페이스

### 메인 화면
- 캐릭터 스탯 표시
- 현재 턴/연령 표시
- 일정 선택 버튼
- 저장/로드 버튼

### 일정 선택 화면
- 활동 목록 (수업/아르바이트/휴식/외출/특별)
- 각 활동의 스탯 변화 미리보기
- 비용 표시
- 선택 완료 버튼

### 이벤트 화면
- 캐릭터 CG/일러스트
- 대화 텍스트
- 선택지 버튼
- 스킵 기능

### 상태 화면
- 상세 스탯 표시
- 성격 성향
- 보유 아이템
- NPC 호감도

## 시스템 밸런스 목표

### 난이도
- **초반**: 쉬움 (시스템 학습)
- **중반**: 중간 (전략 필요)
- **후반**: 어려움 (목표 달성 집중)

### 리플레이 가치
- **다양한 엔딩**: 15개 엔딩
- **스탯 조합**: 여러 육성 루트
- **NPC 관계**: 다양한 관계 발전

### 플레이 시간
- **1회 플레이**: 3시간
- **전 엔딩**: 40~50시간
- **세이브/로드**: 자유로운 사용 가능
