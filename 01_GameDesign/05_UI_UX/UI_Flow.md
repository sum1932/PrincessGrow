# UI Flow

## 화면 전환 플로우

```
[게임 시작]
    ↓
[타이틀 화면]
    ├── 새 게임
    ├── 계속하기 (로드)
    └── 설정
    ↓
[프롤로그]
    ↓
[메인 화면] ←──┐
    ↓         │
    ├── [일정 선택 화면]
    │       ↓
    │   [활동 진행 화면]
    │       ↓
    │   [이벤트 화면] (확률)
    │       ↓
    │   [결과 화면]
    │       ↓
    └───┐   │
        ↓   │
[턴 종료 처리]
    ↓
[저장 여부]
    ↓
[메인 화면] ───┘
    ↓ (144턴 후)
[엔딩 판정]
    ↓
[엔딩 화면]
    ↓
[엔딩 CG/스토리]
    ↓
[엔딩 크레딧]
    ↓
[타이틀 화면]
```

## 화면 상세 플로우

### 1. 타이틀 화면

```
[타이틀 화면]
    ├── [새 게임]
    │       ↓
    │   [프롤로그 스토리]
    │       ↓
    │   [메인 화면]
    │
    ├── [계속하기]
    │       ↓
    │   [로드 화면]
    │       ↓
    │   [메인 화면]
    │
    └── [설정]
            ↓
        [설정 화면]
```

### 2. 메인 화면 → 일정 선택

```
[메인 화면]
    ↓ (일정 선택 버튼)
[일정 선택 화면]
    ├── 수업 선택 (6종)
    ├── 아르바이트 선택 (8종)
    ├── 휴식 선택 (5종)
    ├── 외출 선택 (5종)
    └── 특별 활동 (4종)
    ↓
[선택 확인]
    ↓
[활동 진행 화면]
    ↓
[결과 화면]
    ↓
[이벤트 체크]
    ├── 이벤트 발생 → [이벤트 화면]
    └── 이벤트 없음 → [메인 화면]
```

### 3. 메인 화면 → 상태 확인

```
[메인 화면]
    ↓ (상태 버튼)
[상태 화면]
    ├── 캐릭터 정보
    ├── 스탯 상세
    ├── NPC 호감도
    ├── 보유 아이템
    └── 엔딩 도감
    ↓
[메인 화면] (뒤로가기)
```

### 4. 메인 화면 → 저장/설정

```
[메인 화면]
    ↓ (메뉴 버튼)
[메뉴 화면]
    ├── 저장하기
    │       ↓
    │   [저장 슬롯 선택]
    │       ↓
    │   [저장 완료]
    │
    ├── 설정
    │       ↓
    │   [설정 화면]
    │       ├── 소리
    │       ├── 화면
    │       └── 게임
    │
    └── 타이틀로
            ↓
        [타이틀 화면]
```

## 화면 간 데이터 흐름

### 주요 데이터

| 화면 | 입력 데이터 | 출력 데이터 |
|------|------------|------------|
| **메인** | 현재 스탯, 턴 정보 | - |
| **일정 선택** | - | 선택된 활동 (2개) |
| **활동 진행** | 선택된 활동 | 스탯 변화, 비용, 스트레스 |
| **이벤트** | 현재 스탯, 호감도 | 선택지 결과, 추가 변화 |
| **상태** | 전체 데이터 | - |
| **저장** | 전체 데이터 | 세이브 파일 |

## 핵심 사용자 플로우

### 플레이어의 한 턴

```
1. [메인 화면] 진입
   - 현재 스탯 확인
   - 캐릭터 상태 확인

2. [일정 선택] 클릭
   - 2개 활동 선택
   - 비용/효과 확인

3. [선택 완료]
   - 활동 진행 애니메이션
   - 결과 적용

4. [이벤트 체크]
   - 이벤트 발생 시 시청
   - 선택지 선택 (있을 경우)

5. [턴 종료]
   - 자동 저장
   - 다음 턴 준비

6. 반복 (144턴)
```

### 메뉴 탐색 플로우

```
[메인 화면]
    ├── 상단: 턴/날짜 정보
    ├── 중앙: 캐릭터 + 스탯
    ├── 하단: 버튼 그룹
    │       ├── 일정 선택
    │       ├── 상태 확인
    │       ├── 아이템
    │       └── 메뉴
    └──
```

## 특수 화면 플로우

### 엔딩 플로우

```
[18세 마지막 턴]
    ↓
[엔딩 판정]
    ↓
[엔딩 화면]
    ├── 엔딩 제목
    ├── 조건 요약
    └── [엔딩 CG]
    ↓
[엔딩 스토리]
    - 텍스트로 루아의 미래
    - 관련 NPC들의 반응
    ↓
[크레딧]
    - 스탯 요약
    - 달성 업적
    - 플레이 시간
    ↓
[선택]
    ├── 다시하기 (처음부터)
    ├── 뉴 게임+ (2회차)
    └── 타이틀로
```

### 이벤트 플로우

```
[이벤트 발생 조건 충족]
    ↓
[이벤트 화면]
    ├── 배경 표시
    ├── 캐릭터 CG
    └── 대화 텍스트
    ↓
[선택지] (있을 경우)
    ├── 선택지 1
    ├── 선택지 2
    └── 선택지 3
    ↓
[결과 적용]
    - 스탯 변화
    - 호감도 변화
    - 다음 이벤트 예약
    ↓
[메인 화면]
```

## 화면 전환 효과

### 전환 효과 종류

| 상황 | 효과 | 시간 |
|------|------|------|
| **일반 전환** | 페이드 | 0.3초 |
| **일정 선택** | 슬라이드 업 | 0.4초 |
| **이벤트 진입** | 줌 인 | 0.5초 |
| **이벤트 종료** | 줌 아웃 | 0.3초 |
| **엔딩** | 페이드 + 딜레이 | 2.0초 |
