# 디저트 킹덤 시뮬레이션 가이드

## 📖 개요

이 문서는 디저트 킹덤 게임의 밸런스를 조정하고 시뮬레이션을 실행하는 방법을 설명합니다.

---

## 🚀 시뮬레이션 실행 방법

### 1. 기본 실행

```bash
# 디렉토리 이동
cd C:\우수민\Maker\GameProject\01_GameDesign

# 단일 시뮬레이션 (상세 로그)
python ..\..\game_simulation_full.py --mode single --verbose

# 대량 시뮬레이션 (100회)
python ..\..\game_simulation_full.py --mode batch --count 100

# 히든 엔딩 중점 추적
python ..\..\game_simulation_full.py --mode batch --count 200 --track-npc --track-hidden
```

### 2. 결과 파일 생성

```bash
# 마크다운 결과 파일로 저장
python ..\..\game_simulation_full.py --mode batch --count 100 --format markdown --output 내결과.md
```

### 3. 주요 옵션 설명

| 옵션 | 설명 | 예시 |
|------|------|------|
| `--mode` | 실행 모드 | `single` (1회), `batch` (대량) |
| `--count` | 실행 횟수 | `--count 100` (100회) |
| `--verbose` | 상세 로그 출력 | 턴별 상세 정보 확인 |
| `--track-npc` | NPC 호감도 추적 | 호감도 변화 확인 |
| `--track-hidden` | 히든 엔딩 추적 | 히든 엔딩 달성 조건 분석 |
| `--format` | 출력 형식 | `text`, `markdown` |
| `--output` | 출력 파일명 | `--output 결과.md` |

## 📂 변경 가능한 데이터 파일

### 1. Actions.csv (활동 데이터)
**경로**: `01_GameDesign/Data/Actions.csv`

**변경 가능한 항목**:
- `Effect_HP/Charm/Int/Art/Morality/Stress` : 스탯 변화량
- `Cost_Sweets` : 비용
- `Income_Sweets` : 수입
- `Required_Stat/Value` : 필요 스탯/수치
- `Required_Age` : 필요 나이

**예시**:
```csv
# 매력 수업 너프
ACT_Lesson_Charm_1,매력 수업 - 기본,...,0,20,0,0,0,8,300,0,None,0,0,설명...,TRUE
#                                      ↑ 매력 +20으로 변경 (기존 +24)
```

### 2. Ending_Conditions.csv (엔딩 조건)
**경로**: `01_GameDesign/Data/Ending_Conditions.csv`

**변경 가능한 항목**:
- `Req_HP/Charm/Int/Art/Morality/Stress` : 필요 스탯
- `Req_Favor_Ino/Aileen/Kyle/Lian` : 필요 NPC 호감도
- `Req_Events` : 필요 이벤트
- `Req_Flags` : 필요 플래그

**예시**:
```csv
# 여왕의 길 조건 상향
END_001,여왕의 길,...,5,600+,800+,800+,,600+,,>=80,,,,,,,
#                HP 600+  ↑   Charm 800+  ↑   Int 800+  ↑   Morality 600+  ↑
```

### 3. Events.csv (이벤트 데이터)
**경로**: `01_GameDesign/Data/Events.csv`

**변경 가능한 항목**:
- `Trigger_Value` : 트리거 값
- `Age_Min/Max` : 발생 가능 나이
- `Month/Day` : 발생 월/일
- `Stat_Condition` : 스탯 조건
- `NPC_Condition` : NPC 조건

### 4. NPC_Favor.csv (NPC 호감도)
**경로**: `01_GameDesign/Data/NPC_Favor.csv`

**변경 가능한 항목**:
- `Favor_Level` : 호감도 레벨
- `Min_Favor/Max_Favor` : 호감도 범위

## 🎮 주요 수치별 변경 가이드

### 1. 스탯 효율 조정

#### 문제: 특정 스탯이 너무 쉽게 오름
**해결책**:
```csv
# BEFORE: 도덕 수업이 너무 강함
ACT_Lesson_Moral_1,...,0,0,0,0,20,-3,200,0,...
#                                     ↑ 스트레스 -3 (감소)

# AFTER: 스트레스 증가로 너프
ACT_Lesson_Moral_1,...,0,0,0,0,20,5,200,0,...
#                                    ↑ 스트레스 +5 (증가)
```

#### 문제: 특정 스탯이 너무 안 오름
**해결책**:
```csv
# BEFORE: 체력 단련 효과 부족
ACT_Lesson_HP_1,...,30,-5,0,0,0,10,200,0,...
#                  ↑ HP +30

# AFTER: 효과 상향
ACT_Lesson_HP_1,...,40,-5,0,0,0,10,200,0,...
#                  ↑ HP +40
```

### 2. 엔딩 난이도 조정

#### 문제: 특정 엔딩이 너무 많이 나옴
**해결책**:
```csv
# BEFORE: 성스러운 성녀가 90% 나옴
END_006,...,8,,,,400+,750+,,...
#                    Art 400+  Morality 750+

# AFTER: 조건 상향
END_006,...,8,,,,450+,850+,,...
#                    Art 450+  Morality 850+
```

#### 문제: 히든 엔딩이 너무 안 나옴
**해결책**:
```csv
# BEFORE: 리안 히든 엔딩 1% 미만
END_HIDDEN_001,...,1,,500+,,,,<=400,,,,80-100,EVT_Lian_Secret,,...
#                                                      리안 호감도 80-100

# AFTER: 조건 완화
END_HIDDEN_001,...,1,,450+,,,,<=400,,,,70-100,EVT_Lian_Secret,,...
#                                                      리안 호감도 70-100
```

### 3. 경제 밸런스 조정

#### 문제: 돈이 너무 쉽게 모임
**해결책**:
```csv
# BEFORE: 공원 청소가 사기적
ACT_Job_5,...,0,-3,0,0,10,3,0,100,...
#                                      ↑ 수입 100

# AFTER: 수입 감소
ACT_Job_5,...,0,-3,0,0,10,3,0,60,...
#                                      ↑ 수입 60
```

#### 문제: 스트레스 관리가 너무 쉬움
**해결책**:
```csv
# BEFORE: 휴식이 너무 강함
ACT_Rest_1,...,3,0,0,0,0,-30,0,0,...
#                                  ↑ 스트레스 -30

# AFTER: 효과 감소
ACT_Rest_1,...,3,0,0,0,0,-20,0,0,...
#                                  ↑ 스트레스 -20
```

## 📊 결과 해석 방법

### 1. 엔딩 분포 확인

**이상적인 분포**:
- 가장 많은 엔딩: 15~25%
- 히든 엔딩: 1~3%
- 극소수 엔딩: 0.5~2%

**문제 진단**:
```
엔딩A: 60% 이상 → 조건 상향 필요
엔딩B: 0% → 조건 완화 필요
히든: 0% → 달성 조건 완화 검토
```

### 2. 스탯 성장 분석

**정상적인 성장**:
```
HP: 300~600
Charm: 300~700
Int: 300~700
Art: 300~600
Morality: 300~700
Stress: 0~30 (평균)
```

**문제 진단**:
```
특정 스탯 800+ 과다 → 해당 스탯 얻는 활동 너프
Stress 50+ 평균 → 휴식 활동 버프 필요
```

### 3. NPC 호감도 확인

**히든 엔딩 관련 NPC**:
```
리안: Bonded(81-100) 달성률 체크
      → 5% 미만이면 완화 필요
이노: Bonded 달성률 체크
      → 80% 이상이면 새로운 여왕 엔딩 쉬움
```

### 4. 활동별 실행 비율

**이상적인 비율**:
```
Job: 30~35%
Rest: 20~25%
Outing: 20~25%
Lesson: 15~20%
Special: 5~10%
```

**문제 진단**:
```
Lesson 30% 이상 → 수업이 너무 효율적
Job 40% 이상 → 아르바이트가 사기적
```

## 💡 밸런스 조정 팁

### 1. 점진적 조정
```
1차: ±10~20% 조정
2차: 추가 ±10% 조정
3차: 미세 조정 (±5%)
```

### 2. 한 번에 하나씩
```
❌ 매력 수업 너프 + 엔딩 조건 상향 + 휴식 버프 동시
✓ 매력 수업만 먼저 조정 → 시뮬레이션 → 다음 조정
```

### 3. 극단적 값 피하기
```
❌ 스트레스 -50 (완전해소)
❌ 스트레스 +50 (즉사)
✓ 스트레스 -30 (적절한 휴식)
✓ 스트레스 +15 (부담스러운 수업)
```

### 4. 참고: 스탯 상한선
```
최대 가능 스탯 (18세 기준):
- 집중 투자 시: 800~1000
- 균형 투자 시: 500~600
- 방치 시: 100~200
```

## 🎯 추천 실험 시나리오

### 시나리오 1: 히든 엔딩 확률 조정
```
목표: 히든 엔딩 3~5% 달성

1. 리안 등장 시기: 8세 → 6세
2. 리안 호감도 상승: +5 → +8
3. 리안 히든 엔딩 조건: 호감도 80 → 75
```

### 시나리오 2: 엔딩 다양성 확보
```
목표: 10개 이상 엔딩 균등 분포

1. 가장 많은 엔딩 조건 상향 (5%p 감소 목표)
2. 가장 적은 엔딩 조건 완화 (3%p 증가 목표)
3. 중복 조건이 있는 엔딩 차별화
```

### 시나리오 3: 스트레스 관리 중요성
```
목표: 휴식-수업-아르바이트 삼각 균형

1. 휴식 버프 (-20 → -30)
2. 수업 너프 (도덕 수업 스트레스 증가)
3. 아르바이트 스트레스 조정
```

## 📞 문제 해결

### 시뮬레이션 실행 안 됨
```
오류: File not found
해결: cd 명령으로 디렉토리 먼저 이동
```

### CSV 변경 후 오류
```
오류: 데이터 로드 실패
해결: 
1. 쉼표(,) 개수 확인
2. 한글 인코딩 UTF-8 확인
3. 빈 줄이나 공백 확인
```

### 결과 이상함
```
증상: 모든 엔딩이 동일하거나 0%
해결:
1. CSV 파일 저장 확인
2. 캐시 삭제 후 재실행
3. 원본 CSV로 복원 후 테스트
```
