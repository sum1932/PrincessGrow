# Items 데이터 관리

## 파일 구조

### Excel/CSV 파일
- **Items_Master.csv**: 전체 아이템 마스터 데이터
- **Gifts.csv**: NPC 선물 데이터
- **Equipment.csv**: 장비/의상 데이터 (추가 예정)
- **Consumables.csv**: 소비 아이템 상세 (추가 예정)

### 문서 파일
- **Consumables.md**: 아이템 상세 설명 문서
- **Item_Design.md**: 아이템 디자인 컨셉 (추가 예정)

## 사용 방법

### Excel에서 CSV 파일 열기 (한글 깨짐 방지)

**방법 1: 데이터 가져오기 (추천)**
1. Excel 실행
2. **데이터** 탭 → **텍스트/CSV 가져오기**
3. CSV 파일 선택
4. **파일 원본**을 **65001: 유니코드(UTF-8)**로 선택
5. **불러오기**

**방법 2: 메모장 변환**
1. CSV 파일을 메모장으로 열기
2. **다른 이름으로 저장**
3. 인코딩을 **UTF-8 BOM**으로 선택
4. 저장한 파일을 Excel로 열기

**방법 3: Google Sheets**
1. Google Sheets에서 **파일 → 가져오기** → **업로드**
2. CSV 파일 업로드
3. 인코딩: **UTF-8** 선택
4. 데이터 확인 후 다운로드

### Excel에서 작업 후 저장
1. 데이터 수정/추가
2. **파일** → **다른 이름으로 저장**
3. 파일 형식: **CSV(쉼표로 분리)** 선택
4. 주의: Excel의 기본 CSV 저장은 한글이 깨질 수 있으므로, UTF-8 인코딩 확인 필수

### Unity에서 사용
1. CSV 파일을 Unity 프로젝트의 Resources 폴더에 복사
2. CSV 파서로 데이터 로드
3. ScriptableObject로 변환

## 데이터 규칙

### Item_ID 규칙
- ITEM_xxx: 소비/기타 아이템
- EQ_xxx: 장비/의상
- GIFT_xxx: 선물
- SPEC_xxx: 특별 아이템

### Rarity (희귀도)
- 1: 일반 (☆)
- 2: 희귀 (☆☆)
- 3: 영웅 (☆☆☆)
- 4: 전설 (☆☆☆☆)
- 5: 신화 (☆☆☆☆☆)
