## 효과음 기술 사양

### 파일 형식
- **포맷**: OGG Vorbis
- **비트레이트**: 128kbps
- **샘플레이트**: 44.1kHz
- **채널**: Mono (UI), Stereo (배경)

### 길이 가이드
| 타입 | 길이 | 예시 |
|------|------|------|
| **UI** | 0.1~0.5초 | 버튼 클릭 |
| **효과** | 0.5~2초 | 아이템 획득 |
| **알림** | 1~3초 | 이벤트 |
| **배경** | 3~5초 | 비/바람 |

### 볼륨 설정
| 상황 | 볼륨 |
|------|------|
| **기본** | 80% |
| **UI** | 100% |
| **알림** | 90% |
| **배경** | 60% |

## 네이밍 규칙

### 파일명 규칙
```
[카테고리]_[설명].ogg

예시:
- ui_click.ogg
- stat_up_s.ogg
- npc_happy.ogg
- event_start.ogg
```

### ID 네이밍
```
[PREFIX]_[번호]

PREFIX:
- UI: UI 사운드
- STAT: 스탯 관련
- ACT: 활동/일정
- NPC: NPC 관련
- EVT: 이벤트
- EMO: 감정
- ITEM: 아이템
- SYS: 시스템
- END: 엔딩
```
