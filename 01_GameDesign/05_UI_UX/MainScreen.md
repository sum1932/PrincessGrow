# Main Screen

## 메인 화면 개요

게임의 핵심 화면. 현재 상태 확인과 일정 선택의 중심.

---

## 상세 구성

### 1. 상단바 (Top Bar)

```
┌─────────────────────────────────────────────────────────────┐
│  🎂 8세  │  📅 2026년 3월  │  🔄 턴: 24/144  │  💰 1,250  │
└─────────────────────────────────────────────────────────────┘
```

| 요소 | 내용 | 표시 |
|------|------|------|
| **연령** | 현재 루아의 나이 | 🎂 8세 |
| **날짜** | 현재 연도/월 | 📅 2026년 3월 |
| **턴** | 진행 상황 | 🔄 24/144 |
| **자산** | 보유 스위트 | 💰 1,250 |

### 2. 캐릭터 영역 (Character Area)

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│              [성격: 활발한]                                │
│                                                             │
│                    ┌─────────────┐                         │
│                    │             │                         │
│                    │   루아     │                         │
│                    │   (8세)    │                         │
│                    │             │                         │
│                    │  [스탠딩   │                         │
│                    │    CG]     │                         │
│                    │             │                         │
│                    └─────────────┘                         │
│                                                             │
│        "오늘은 무엇을 할까요?"                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**특징:**
- 중앙에 루아의 스탠딩 CG 배치
- 성격/성향 표시
- 간단한 대사 표시 (랜덤 또는 상황별)
- 터치/클릭 시 감정 표정 변화 (선택사항)

### 3. 스탯 요약 영역 (Stats Summary)

```
┌─────────────────────────────────────────────────────────────┐
│  체력    [████████░░] 450    │    지능    [███████░░░] 420  │
│  매력    [██████░░░░] 380    │    예술    [████░░░░░░] 250  │
├─────────────────────────────────────────────────────────────┤
│  스트레스 [████░░░░░░] 35%  (양호)                         │
└─────────────────────────────────────────────────────────────┘
```

| 스탯 | 표시 방식 | 상태 |
|------|----------|------|
| **체력** | 게이지 바 + 수치 | 정상/양호/주의 |
| **매력** | 게이지 바 + 수치 | 정상/양호/주의 |
| **지능** | 게이지 바 + 수치 | 정상/양호/주의 |
| **예술** | 게이지 바 + 수치 | 정상/양호/주의 |
| **스트레스** | 게이지 바 + 퍼센트 + 상태 텍스트 | 정상/양호/피로/과로 |

**터치 시:** 상세 스탯 화면으로 이동

### 4. 하단 버튼 영역 (Bottom Buttons)

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐         │
│   │ 일정   │  │ 상태   │  │ 아이템 │  │  메뉴  │         │
│   │ 선택   │  │ 확인   │  │    ☰   │  │   ☰    │         │
│   └────────┘  └────────┘  └────────┘  └────────┘         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

| 버튼 | 기능 | 아이콘 |
|------|------|--------|
| **일정 선택** | 일정 선택 화면으로 | 📅 |
| **상태 확인** | 상세 스탯 화면으로 | 📊 |
| **아이템** | 인벤토리 화면으로 | 🎒 |
| **메뉴** | 설정/저장 메뉴 | ☰ |

## 시각적 디자인

### 색상 팔레트 (Pastel/Dessert)

| 용도 | 색상 | HEX |
|------|------|-----|
| **배경** | 크림색 | #FFF8E7 |
| **주요 버튼** | 베이비 핑크 | #FFB6C1 |
| **보조 버튼** | 라벤더 | #E6E6FA |
| **강조** | 민트 | #98FF98 |
| **텍스트** | 다크 초콜릿 | #3D2B1F |
| **경고** | 피치 | #FFDAB9 |

### 폰트

| 용도 | 폰트 | 크기 |
|------|------|------|
| **제목** | 둥근모꼴 | 24px |
| **본문** | 나눔고딕 | 16px |
| **버튼** | 둥근모꼴 | 18px |
| **수치** | 나눔고딕 (볼드) | 20px |

### UI 요소 스타일

#### 버튼
```
┌─────────────────┐
│  [둥근 모서리]  │
│  [그라데이션]   │
│  [그림자 효과]  │
└─────────────────┘
```
- 모서리: 둥글게 (border-radius: 15px)
- 그라데이션: 상단 밝게 → 하단 어둡게
- 그림자: 부드러운 드롭 섀도우

#### 게이지 바
```
[배경: 연한 회색]
[게이지: 그라데이션 색상]
[테두리: 둥근 사각형]
```
- 체력: 코랄 핑크
- 매력: 로즈 핑크
- 지능: 스카이 블루
- 예술: 라벤더
- 스트레스: 경고색 (주황/빨강)

## 상호작용

### 터치/클릭 동작

| 영역 | 동작 | 결과 |
|------|------|------|
| **캐릭터 CG** | 터치 | 감정 표정 변화 |
| **스탯 게이지** | 터치 | 상세 스탯 화면 |
| **일정 선택 버튼** | 클릭 | 일정 선택 화면 |
| **상태 확인 버튼** | 클릭 | 상세 스탯 화면 |
| **아이템 버튼** | 클릭 | 인벤토리 화면 |
| **메뉴 버튼** | 클릭 | 메뉴 팝업 |

### 애니메이션

| 상황 | 애니메이션 | 시간 |
|------|-----------|------|
| **화면 진입** | 페이드 인 | 0.3초 |
| **스탯 변화** | 게이지 바 움직임 | 0.5초 |
| **캐릭터 터치** | 표정 변화 | 0.2초 |
| **버튼 호버** | 살짝 커짐 + 밝기 증가 | 0.1초 |
